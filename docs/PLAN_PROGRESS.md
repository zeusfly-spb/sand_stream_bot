# SandStreamBot — прогресс плана развития

Основной план проекта: [SandStreamBot_plan_razvitiya.pdf](SandStreamBot_plan_razvitiya.pdf).

## Этап 0. Очистка и стабилизация основы

**Статус: завершён.**  
**Дата проверки:** 28 ноября 2026 г.

### Выполнено

- Обновлена документация README: инструкции и описание возможностей приведены в соответствие с текущей реализацией.
- Минимальная версия Python и команда создания виртуального окружения уточнены.
- Общая проверка прав администратора вынесена в `app/services/access.py`.
- Незавершённые кнопки и сценарии подписок/геопоиска скрыты или удалены из пользовательского интерфейса и FSM до реализации соответствующих этапов.
- Список зависимостей `requirements.txt` очищен от неиспользуемых пакетов; оставлены прямые зависимости проекта.
- Удалены неиспользуемые вспомогательные функции геопоиска.
- Удалено локальное кеширование справочников: списки материалов и городов загружаются из БД при открытии соответствующего шага, поэтому изменения в Django Admin видны без перезапуска бота.

### Проверки

Проверки выполнены в активном виртуальном окружении `.venv` на локальной ветке `beta`.

| Проверка | Результат |
|---|---|
| `git pull origin beta` и сверка HEAD | Успешно, локальная ветка на коммите `21bfd6a` |
| `python -m pip install -r requirements.txt` | Все зависимости установлены |
| `python web\\manage.py check` | Успешно: проблем не обнаружено |
| `python -m compileall app web` | Успешно: ошибок компиляции нет |

### Критерии завершения

- Документация соответствует текущему состоянию проекта.
- Проверки доступа к административным функциям используют общий helper.
- Не реализованные функции не представлены пользователю как доступные.
- Зависимости и код прошли локальные проверки.
